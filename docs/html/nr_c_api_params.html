NR 參數：外部與內部 — AnrConfig

本頁是整合者視角的參數清單，呼叫順序與錯誤語意在 nr_c_api.html，演算法與時序在 nr.html。每一列都可在 NR/c_impl/include/anr_types.h（struct 第 56–110 行、預設值第 164–231 行、preset 第 241–273 行、驗證第 309–467 行）查到；預設值欄是 balanced、16k/256 的實際讀回值（anr_config_for_mode_grid() 列印），其他 grid 的時間常數依 hop 重定時，請由 config 讀回，不要寫死。

1. 分類準則與總數

類別定義欄位數
外部 A描述部署環境（取樣率、格點）或選一個 AnrMode；有界、效果單調，錯值會被驗證擋下3 個概念：sample_rate、fft_size、AnrMode（frame_size／hop_size 是衍生值，共 4 欄）
外部 B四個 preset 本來就在動的強度旋鈕，有耦合，開放時要夾限4
內部時間常數、門檻、遲滯、pool 佈局欄位、預設關閉的研究開關；錯值會讓追蹤靜默失效，或是多個參數聯合調出來的33（其中 1 個 alpha_g 不參與運算）

AnrConfig 共 41 欄（4＋4＋33）。struct 完整攤在公開 header 裡，「內部」是約定不是編譯器強制：要對外釋出時，只轉出外部 A／B 欄位，其餘一律取自 anr_config_for_mode_grid()。

2. 外部參數

2.1 A 級：建立時決定，之後不可變

名稱型別／合法值預設作用設定時機
sample_rateint；8000／16000／48000呼叫端指定取樣率。不支援的值（例如 44100）constructor 不回報錯誤：anr_config_for_mode()／anr_default_config() 給出 fft_size==0 的 config，anr_config_for_mode_grid() 則保留你傳入的 fft_size；兩者都要靠 anr_validate_config() 才現形（回 false）建立時；換了必須重建
fft_sizeint；8k→128／256，16k→256／512，48k→1024anr_default_fft_size()：8k→128、16k→256、48k→1024轉換長度＝frame_size，hop_size = fft_size/2（固定 50 % overlap，不補零）。hop 短＝延遲低、呼叫多；hop 長＝頻率解析度高。與 AEC 串接時 8 kHz 預設不同（AEC 是 256），要由上層解出同一組 grid 明確傳給兩邊建立時；換了必須重建
frame_size／hop_size衍生：frame_size==fft_size、frame_size==2×hop_size由 constructor 填不是獨立設定，手動改成不一致會被拒。對外介面不要暴露—
AnrMode（anr_config_for_mode*()、anr_set_mode()）ANR_MODE_MILD(0)／MODERATE(1)／BALANCED(2)／AGGRESSIVE(3)BALANCED抑噪深度的單一入口，一次設定下面 B 級的四個旋鈕建立時，或執行期 anr_set_mode()

2.2 B 級：強度細調（preset 動的就是這四欄）

名稱validator 範圍mild／moderate／balanced／aggressive建議夾限（parameter_tuning.md，本頁未重新量測）調高／調低耦合與注意
g_min_db（振幅 dB，÷20）有限值 [-80, 80]−20／−23／−25／−28−20 ~ −45調低：背景更乾淨，處理痕跡與傷語音風險上升；調高：留底噪、語音自然耦合：speech_protect_floor=true（預設）時要求 speech_protect_floor_db(−15) ≥ g_min_db，所以預設下實際上限是 −15（實測 −10 被拒、−15 接受）
xi_min_db（功率 dB，÷10）[-80, 80]−10／−10／−10／−12−10 ~ −20調低：殘留底噪更少、痕跡更明顯；調高：保留自然底噪。控制殘留深度的主旋鈕preset 只用 −10／−12
q開區間 (0, 1)（0 與 1 被拒）0.58／0.54／0.52／0.450.2 ~ 0.7調高：保守、保語音；調低：抑噪深連動幀級語音閘：生效值 = speech_protect_frame_threshold + (q − 0.52)（0.61／0.57／0.55／0.48，可用 anr_get_speech_protect_frame_threshold() 讀回），所以 q 不是獨立旋鈕；cross_band_speech_prior 開啟時另須 max_q ≥ q
noise_over_subtraction[1.0, 4.0]1.2／1.3／1.4／1.31.0 ~ 2.0調高：壓得更深（SPP 與 gain 看到的噪聲底乘上這個倍率）等於 1.0 且沒有 extra_noise_psd 時不複製噪聲底

四個旋鈕是一組聯合調出來的操作點：建議對外只開 g_min_db 與 xi_min_db，q 與 noise_over_subtraction 視需要。四級 preset 以外的所有欄位完全相同（幀級語音閘的生效值除外，見上）。

2.3 邊界項：手冊的症狀處方會用到，但不建議開放給第三方

名稱預設（16k/256）範圍為什麼不開
alpha_decay0.902789[0,1]真正生效的增益下降平滑。musical noise 的處方是調高它，但它與 alpha_attack、alpha_xi 聯合調過，單獨動會改起音與尾音；四級 preset 共用
alpha_attack0.387298[0,1]增益上升平滑，同上

3. 內部參數（存在且可調，但不建議開放）

位置一律是 AnrConfig 欄位；「pool」表示該欄決定 anr_get_mem_size()，anr_reconfigure() 會拒絕改它。

家族欄位（預設、validator 範圍）為什麼不開放
噪聲追蹤器（MCRA，6）alpha_s 0.959796 [0,1]；alpha_d 0.921954 [0,1]；alpha_p 0.275946 [0,1]；L 64 1..320（pool）；delta_db 10 [-80,80]；num_init_frames 25 1..200（pool，也是開頭 pass-through 的長度）追蹤器核心常數，彼此耦合；L 與 num_init_frames 決定記憶體需求，執行期不可改，改它們要重建並重新查 pool 大小；parameter_tuning.md 明列「不建議在 release 動」
先驗 SNR 平滑（1）alpha_xi 0.959166 [0,1]decision-directed 平滑，是 musical noise 的槓桿，與增益平滑聯合調過
增益平滑（3）alpha_attack 0.387298、alpha_decay 0.902789（皆 [0,1]，見 2.3）；alpha_g 0.902789 [0,1]alpha_g 會被複製進實例、會過驗證，但 calculate_gain() 從不讀它（anr.c 只在 apply_gain_config_scalars() 賦值）；要調平滑請改 alpha_decay
場景切換（5）scene_change_threshold_db 10 [-80,80]；scene_change_min_frames 7（≥0，無上限）；scene_change_blend 0.5 [0,1]；scene_change_flatness_threshold 0.4 [0,1]；broadband_threshold 1.0 [0,1]（1.0＝停用）全是門檻與遲滯，「追不上」與「誤觸」是同一軸的取捨，放給外部等於把這個取捨丟出去。scene_change_blend 是保留舊噪聲底的比例（新 = blend·舊 + (1−blend)·觀測；1.0 只讓 noise_psd 維持原值，S_min 與最小值環仍會用當前 S 重新播種，所以不是停用）；broadband_threshold<1 時，內部 SPP>0.5 的 bin 比例超過它，更新慣性裡的 SPP 權重線性縮小，噪聲底追得更快
低頻語音保護（預設開，4）speech_protect_floor true；speech_protect_floor_db −15 [-80,0]；speech_protect_threshold 0.0 [0,1]；speech_protect_frame_threshold 0.55 [0,1]語音頻帶（80～4000 Hz）SPP 平均達幀級語音閘時，把低於 noise_gate_lf_hz 的 bin 的增益托在 −15 dB 以上；閘門值隨 q 位移；speech_protect_floor_db 與 g_min_db 有耦合（見 2.2）
speech-aware 噪聲追蹤（預設開，5）speech_aware_noise_tracking true；alpha_d_speech 0.974679 [0,1)；noise_gate_xi_db 3 [-80,80]；noise_gate_lf_hz 300 (0, sr/2]；noise_gate_frame_frac 0.5 [0,1]語音頻帶內 xi 超過門檻的 bin 比例過半時，低頻噪聲底的上升速度被 alpha_d_speech 限住。改這幾欄的 anr_reconfigure() 會重置共用 frame 狀態（slow_lf_rise、make-up 先驗）；noise_gate_lf_hz 同時決定上一列的保護頻帶
預設關閉的研究欄位（9）cross_band_speech_prior false、_max_q 0.54 (0,1)、_alpha 0.90 [0,1)；dd_from_gmmse false；makeup_gain false、makeup_prior_xi_db 3（保留欄位，make-up 實際用 noise_gate_xi_db）、makeup_blim 0.5 (0,1)、makeup_up_slope 1.3 ≥0、makeup_down_slope 0.3 [0,1]實驗開關，header 明寫 optional、off by default；改 cross_band_* 的 reconfigure 會重置跨頻先驗狀態。另有兩個 inline 疊加函式 anr_apply_speech_protection_experiment()、anr_apply_cross_band_speech_experiment()（"not a strength preset"），屬研究用，不對外

3.1 比內部欄位更深：編譯期選項（不是 runtime 參數）

改變的是演算法實作路徑，參與 build 識別（CFG_SIG），不同組合的產物放在不同 bin/ 目錄。預設建置（DEBUG=0）啟用六項：USE_FAST_GAIN_SMOOTHING、USE_SHARED_XI_RATIO、USE_OPTIMIZED_MIN_BUFFER、USE_OPTIMIZED_E1、USE_SINGLE_CLAMP、USE_INCREMENTAL_MIN（NR/c_impl/Makefile）。USE_STANDARD_MATH（make debug，同時關閉六項）改走 libm；USE_FAST_PERCENTILE 以 mean×0.23 取代精確 30th percentile，省一塊 percentile scratch。SIMD=0|1 只選手寫核心，不改演算法。

4. 什麼時候改什麼

時機可改方法
建立時（之後不可變）sample_rate、fft_size（連帶 frame_size／hop_size）、L、num_init_framesanr_config_for_mode_grid() → anr_validate_config() → anr_get_mem_size() → anr_init()／anr_create()。建立後改手上那份 AnrConfig 沒有效果（已複製）
執行期（hop 之間，不重配記憶體、保留追蹤狀態）上表其餘所有欄位實例等於 canonical preset：anr_set_mode()。疊了自己覆寫：重組整份 config 後 anr_reconfigure()。回 −1 時什麼都不寫
換串流／換 grid—換串流：anr_reset()（不保留追蹤狀態，之後 num_init_frames 個 hop 再次 pass-through）；換 grid、L、num_init_frames：destroy 後重建

library 沒有 anr_get_config()：要「只改一個旋鈕」，必須自己持有一份目前的 AnrConfig。

5. 驗證規則（anr_validate_config()）

anr_create／anr_get_mem_size／anr_init／anr_reconfigure 都先驗；失敗回傳依序是 NULL／0／NULL／−1，且不寫任何狀態。

類別規則（anr_types.h 行號）
grid（312–343）取樣率三值之一；fft_size 為 2 的次方且 ≤8192；frame_size==fft_size；frame_size==2×hop_size；只有 8k/128、8k/256、16k/256、16k/512、48k/1024 五組合法
儲存（345–350）L 1..320；num_init_frames 1..200；scene_change_min_frames ≥ 0
浮點（352–464）全部須有限（非 NaN／Inf）且在各自範圍內：係數 [0,1]、dB [-80,80]；q 開區間 (0,1)；noise_over_subtraction [1,4]；makeup_blim (0,1)
耦合（363–384）speech_protect_floor 開啟時 speech_protect_floor_db ≥ g_min_db；cross_band_speech_prior 開啟時 cross_band_speech_prior_max_q ≥ q
anr_reconfigure() 另加sample_rate／frame_size／hop_size／fft_size／L／num_init_frames 必須等於實例當下的值（anr.c）
anr_set_mode()mode 須在 enum 內（anr_nr_mode_is_valid()），否則 −1

validator 只擋崩壞，不擋音質：例如 broadband_threshold=0.5（啟用寬頻閘）會被接受。

6. 函式分級：整合者實際呼叫 vs 內部

級別函式（anr.h、anr_types.h）
A 最小必要anr_config_for_mode()／anr_config_for_mode_grid()、anr_validate_config()、anr_create()，或 anr_get_mem_size() + anr_init()、anr_process()（或 anr_process_gain() + anr_get_gain()）、anr_reset()、anr_destroy()；FFT／window／OLA 由呼叫端用 audiolib 的 fft_* 自備
B 常用選用anr_set_mode()、anr_reconfigure()、anr_get_hop_size()／anr_get_frame_size()／anr_get_n_freqs()（配置 buffer 用，不要硬編）、anr_is_initialized()、anr_default_config()／anr_default_config_for_grid()、anr_default_fft_size()、anr_nr_mode_is_valid()／anr_nr_mode_from_name()／anr_nr_mode_name()
C 串鏈anr_process_gain() 的 extra_noise_psd（AEC 的 r2 / 32768² 併入噪聲底）；anr_retime_alpha()／anr_retime_alpha_ref()／anr_retime_frames()／anr_retime_frames_ms()（把某 grid 調好的係數換到另一 grid，參數無效時原樣回傳／回 0，不報錯）。範例層另有 pipelines/samples/se_anr_stage.h 的 se_anr_stage_gain()（複製改用，非函式庫 ABI）
D 診斷anr_get_noise_psd()、anr_get_gain()、anr_get_speech_protect_frame_threshold()、anr_debug_status() → AnrDebugStatus
E 內部，不得依賴noise_estimator.h、spp_estimator.h（denoiser 自行建立與驅動）；anr_internal.h（noise_estimator_apply_config_scalars()、*_shared_startup()、spp_apply_config_scalars()、ANR_VECTOR／ANR_TWIN）；anr_apply_speech_protection_experiment()、anr_apply_cross_band_speech_experiment()（header 可見的研究用疊加）

7. 逐欄位調整方向（取自手冊 §4，只列會被症狀處方用到的欄位）

欄位調大／調高調小／調低
alpha_xi更平滑、musical noise 更少，起音較鈍反應快，容易出現孤立的增益跳動
alpha_decay增益下降慢，musical noise 明顯減少，尾音拖長噪聲收得快，可能粗糙
alpha_attack起音較鈍但更平順起音更清楚，噪聲易短暫漏出
alpha_s噪聲追蹤更穩、對瞬態不敏感反應快但估計抖動
alpha_d噪聲底更新更慢，不易把語音吸收進噪聲底追噪聲底快，但易吃掉語音
alpha_p語音存在指示判定穩定但反應慢反應快但抖
L（pool）不易把持續語音誤判為噪聲，噪聲底上升時追得慢追得快，長句語音可能被當噪聲
delta_db更難判為語音，噪聲估計易吸收訊號（抑噪深、傷語音風險高）更容易判為語音，噪聲估計更保守
num_init_frames（pool）初始噪聲估計更可靠，開頭未處理的時間更長更快進入處理，初始估計較差（under-fit）
scene_change_threshold_db更保守更容易判為場景變化（追得快，誤判也多）
scene_change_min_frames只有持續的變化才算數，抗誤觸但反應慢反應快但容易被瞬態誤觸
scene_change_blend保留更多舊噪聲底；1.0＝確認場景變化時 noise_psd 不變（S_min／最小值環仍重新播種）幾乎整個換成當前觀測，切換快但誤判風險高
scene_change_flatness_threshold只有很像噪聲的頻譜才觸發，音樂／語音不易誤觸較寬鬆
broadband_threshold1.0＝停用<1.0 時寬頻噪聲突然出現後更快追上
