NR · 單聲道降噪

單聲道 V3-2 降噪。每 hop 傳入複數頻譜，由呼叫端負責 FFT、視窗與 overlap-add。

先處理一段 WAV

將 audiolib/ 放在本庫旁邊，從 NR 根目錄執行。

make -C c_impl
bin="$(make -s -C c_impl print-bin-dir)"
"$bin/denoise_wav" input.wav output.wav --nr-level 2

使用 C 函式庫

初始化與逐 hop 呼叫
配置 instance、傳入複數頻譜、取得或套用增益，以及在切流時 reset。串在 AEC 之後時，NR 增益交給 aec_apply_gain()／aec_apply_cng() 的順序在 §4.1。
可編譯的整合範例
從 PCM 到 PCM 的整份串流程式（window、FFT、OLA、reset）、static memory 路徑、只取增益與執行期換強度。
訊號流程與延遲
核對 STFT／OLA、噪音估計初始化、串在 AEC 之後的資料流和時序。
強度與參數
選擇 level、保留設定覆寫，以及查詢參數限制。
C 使用手冊
每支函式的錯誤語意表、交付檔案與連結方式、依賴的 FFT 層；按症狀調整。

使用 Python 參考實作

python3 -m pip install -r python/requirements.txt
python3 python/process_audio.py input.wav --versions V3-2 --nr-mode balanced --mode full --fft-size 256

C 的 --nr-level 對應 Python 的 --nr-mode；Python 收 mild、moderate、balanced、aggressive，C 只收數字 0..3（mild、moderate、balanced、aggressive），其他值結束碼 2。
