機率計算與決策流程

機率計算公式

// 高斯機率密度函數 P(x|μ,σ) = (1/σ) × exp(-(x-μ)²/(2σ²)) // 對每個頻帶計算 P(noise) = Σ weight[k] × P(feature|noise) P(speech) = Σ weight[k] × P(feature|speech) // 對數似然比 (LLR) LLR = log₂(P(speech)) - log₂(P(noise))

LLR 解讀

LLR > 0 → 偏向語音

LLR < 0 → 偏向噪音

LLR = 0 → 不確定

決策邏輯

局部測試 (Local Test)

if (LLR[band] × 4 > localThreshold) vadflag = 1; // 單頻帶判定

全局測試 (Global Test)

sum = Σ (LLR[i] × weight[i]); if (sum >= globalThreshold) vadflag = 1; // 全局判定
任一測試通過即判定為語音

四種積極模式設定

Mode 名稱 Local Threshold Global Threshold 適用場景 特性
0 Quality 24 57 高品質通話 避免漏檢，可能有誤檢
1 Low Bitrate 37 100 一般使用 平衡模式
2 Aggressive 82 285 過濾背景噪音 較嚴格判定

閾值越低

  • 更容易判定為語音
  • 減少漏檢 (False Negative)
  • 可能增加誤檢 (False Positive)

閾值越高

  • 更嚴格的語音判定
  • 減少誤檢 (False Positive)
  • 可能增加漏檢 (False Negative)

模型更新機制

噪音模型更新

條件：vadflag = 0 (判定為噪音)

// 更新速率 (較慢) kNoiseUpdateConst = 655 // ≈ 2% // 均值更新 nmk_new = nmk_old + delta × 0.02 // 長期背景修正 (追蹤最小值) nmk = nmk + (min_100frames - nmk) × 0.6
更新較慢，保持穩定性

語音模型更新

條件：vadflag = 1 (判定為語音)

// 更新速率 (較快) kSpeechUpdateConst = 6554 // ≈ 20% // 均值更新 smk_new = smk_old + delta × 0.2 // 方差更新 ssk_new = ssk_old + correction
更新較快，適應不同說話者
模型分離保護：當語音與噪音模型過於接近時，系統自動將語音模型上推 80%，噪音模型下推 20%，確保區分能力。

GMM vs 簡單能量閾值

GMM VAD

輸入 → 6頻帶分解 → 各頻帶能量 ↓ GMM 機率計算 P(speech), P(noise) ↓ LLR = log(Ps/Pn) ↓ 加權決策 + 閾值比較 ↓ VAD 輸出

簡單能量閾值

輸入 → 計算總能量 ↓ E = Σ x[n]² ↓ if (E > threshold) ↓ VAD 輸出
特性 GMM VAD 簡單能量閾值
特徵維度 6 維 (各頻帶) 1 維 (總能量)
頻譜資訊 保留 丟失
適應性 自動更新 需手動調整
計算複雜度 中 低

參數調整指南

問題：語音漏檢 (False Negative)

症狀：說話時 VAD 經常返回 0

解決方案：

  • 降低 localThreshold
  • 降低 globalThreshold
  • 增加 OverHang 時間
  • 使用 mode = 0 (Quality)

問題：噪音誤檢 (False Positive)

症狀：沒說話時 VAD 經常返回 1

解決方案：

  • 提高 localThreshold
  • 提高 globalThreshold
  • 加快 kNoiseUpdateConst
  • 使用 mode = 2 或 3

關鍵常數參考

常數 預設值 說明 調整效果
kNoiseUpdateConst 655 (≈2%) 噪音模型更新速率 增大 → 更快適應噪音變化
kSpeechUpdateConst 6554 (≈20%) 語音模型更新速率 增大 → 更快適應不同說話者
kMinStd 384 最小標準差 防止模型過窄

長期穩定性分析

問題：寬鬆閾值 + 持續更新 Speech GMM 會導致退化嗎？

潛在退化問題

  • 語音模型均值漂移：噪音樣本被錯誤用於更新
  • 語音模型方差增大：混入異質樣本
  • 區分能力下降：兩模型逐漸相似
  • 噪音模型過時：vadflag=1 時不更新

內建保護機制

  • 模型分離強制：自動維持最小距離
  • 均值範圍限制：防止無限漂移
  • 標準差下限：防止模型崩塌
  • 最小值追蹤：長期背景修正

建議解決方案

定期重置

每 N 幀重置

高置信度更新

LLR 夠高才更新

能量門檻

能量夠高才更新

凍結模型

設定更新率為 0

結論與建議

> 20 dB

高 SNR 環境

  • 簡單能量閾值可能足夠
  • 計算成本更低
  • 需手動調整閾值
10-20 dB

中 SNR 環境

  • GMM 開始發揮優勢
  • 頻譜分解價值顯現
  • 自適應機制有幫助
< 10 dB

低 SNR 環境

  • GMM 明顯更好
  • 頻譜分解必要
  • 但效果也會下降
核心價值： GMM VAD 的優勢在於 (1) 頻譜分解 (2) 機率模型 (3) 自適應更新
